ICRM Card Descriptions

| Card No. | Variables and Format | Data Description |
|---|---|---|
| 5 | XGZ,YGZ,TGZ,(8F10.0) | XGZ = x coordinate (west to east, m) of ground zero<br>YGZ = y coordinate (south to north, m) of ground zero<br>TGZ = detonation time (s)<br>Normally, this card is blank. |
| 6e | DNS,DMEAN,SD,<br>(8F10.0) | For lognormal particle size distribution (IC(1) = 0 in card 2)<br>DNS = fallout particle density (g cm⁻³). Default value = 2.6<br>DMEAN = median diameter of the particle number vs. diameter distribution (µm). Default value = 0.407 µm and SD = 4.0<br>SD = geometric standard deviation of the particle number vs. diameter distribution (dimensionless)<br>(I, sec. 2.1.6 and I, Appendix A) |
| 6p | DNS,CAYM,EXPO,<br>(8F10.0) | For power-law particle size distribution (IC(1) = 1 on card 2)<br>DNS = same as for 6e.<br>CAYM = k/mass ratio (m<sup>EXPO-1</sup> kg<sup>-1</sup>)<br>EXPO = exponential parameter X (dimensionless)<br>(I, sec. 2.1.6 and I, Appendix B) |
| 6t | DNS,(8F10.0) | For tabular particie size distribution. {IC(1) = 2<br>on card 2)<br>DNS = same as for 6e (I, sec. 2.1.6) |
| 6t:1 | DIAM(1) | For tabular particle size distribution only. (IC(1) = 2 on card 2) |
| ... | ... | DIAM(I) = upper (i.e., larger particle) boundary diameter<br>of the Ith particle size class |
| ... | ... | FMASS(I) = mass or activity fraction (depending on value of<br>IC(5) on card 2) in the Ith particle size class |
| ... | ... | DIAM(NDSTR+1) = lower (i.e., smaller particle) boundary diameter<br>of the NDSTRth particle size class |
| 6t:NDSTR | DIAM(NDSTR),FMASS(NDSTR) | The tabulation begins with the largest particle and continues in<br>order to the smallest. (I, sec. 2.1.6) |
| 6t:NDSTR+1 | DIAM(NDSTR+1) |  |
