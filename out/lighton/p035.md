      <td>5</td>
      <td>XMIN, XMAX, YMIN, YMAX, DGX, DGY, GRUFF, (7F10.3)</td>
      <td>
        XMIN are the minimum and maximum map coordinates (m) in the XMAX west-to-east direction.<br>
        YMIN are the minimum and maximum map coordinates (m) in the YMAX south-to-north direction (m).<br>
        DGX are the map grid intervals (m) in the west-east and south-north directions respectively.<br>
        If DGY is not specified, it is computed by the program to produce a spatially undistorted map (sec. 2.4).<br>
        GRUFF = a combined ground roughness-survey instrument correction factor sometimes applied to calculated map ordinate values. To compare calculated with observed test shot activity data observed over land, GRUFF = 0.5. Default value = 1.0. (sec. 2.4)
      </td>
    </tr>
    <tr>
      <td>6</td>
      <td>NREQ, JC, ICONT, MASCHN, T1, T2, QCUT, CUTMAP, (415, 4F10.0)</td>
      <td>
        Map request card. A map with geometry as specified on the preceding card 5 is computed and printed according to:<br>
        NREQ = map request option code. (See Table 3.)<br>
        JC = 0 or 1, print the map with the two-line E format<br>
        JC = 2, print the map with the two-line F11.3 format (sec. 2.4)<br>
        ICONT ≤ 0 do not compute contour points and do not read cards 7 and 8.<br>
        ICONT = 1 print and punch x,y map coordinate points on the contours specified on card 7, providing a nonblank label is specified on card 8.<br>
        ICONT > 1 compute and print x,y map coordinate points on the contours specified on card 7 provided a nonblank label is entered on card 8. Do not punch the data.<br>
        Applicable only to maps that can be wholly contained by the ordinate array OMAP(NMAP).<br>
        MASCHN Atomic mass number of the mass chain for which activity is to be calculated. Applicable only for NREQ = 14. (See Table 3.)<br>
        T1, T2 time range (hrs relative to detonation) or particle diameter range (µm) for activity or other calculations. (See Table 3.)<br>
        QCUT threshold value for acceptance of a contribution at any map point from an individual fallout deposit increment. Computed by the program if not specified.<br>
        CUTMAP threshold value for print of a completed map ordinate value. Computed by the program if not specified.
      </td>
    </tr>
    <tr>
      <td>7</td>
      <td>CONTUR(8), (8F10.0)</td>
      <td>
        Read only if ICONT.NE.0 (card 6). Values of activity or other quantity, depending on type of map, for which map x,y coordinates are to be printed and punched. These data can be used for contour plotting. A maximum of eight values are allowed per map. Restricted to maps that can be wholly contained in the ordinate array OMAP(NMAP). (sec. 2.6)
      </td>
    </tr>
