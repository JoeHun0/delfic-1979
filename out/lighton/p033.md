---

Cards 8r through 14r are repeated for each wind update and for each turbulence field for which FORM = INPUTADATA (Card 8r).

---

Begin specification of turbulence field to be calculated by Wilkins method. Applies to homogeneous and nonhomogeneous data fields (MC(1) = 0 and MC(1).NE.0), and the turbulence is horizontally isotropic. (I, sec. 3.3). Data are read by Subroutines DATIN and WILKNS.

      <td>6t</td>
      <td>U, ZM, ZO, RL, (4F10.0)</td>
      <td>
        U = surface wind speed (m s⁻¹)<br>
        ZM = height above ground (m) at which U is measured (usually 10m).<br>
        ZO = aerodynamic surface roughness length (m)<br>
        RL = reciprocal of Monin-Obukhov length (m⁻¹)<br>
        These quantities are used to compute $\varepsilon$ as a function of altitude by eq. (I, 3.3.4). On default (blank card), $\varepsilon$ is computed as a function of height by eq. (I, 3.3.5).
      </td>
    </tr>

</table>

---

Cards 5t and 6t are repeated for each update for which turbulence is to be calculated by Wilkins' method.

---

DTM data input is terminated by a card of type 5h, 8r, 5t with SPEC = NOΔMOREADATA (Cols. 1 - 12).
